# 🎬 Ayat & Nasihat Video Maker

Ek **free**, **offline-friendly** web app jo Quran ki ayat, hadees ya achi nasihat
se **animated videos** banati hai — Reels, Shorts aur Posts ke liye.

Koi server nahi, koi signup nahi, koi API key nahi. Sab kuch browser me hota hai.

## ✨ Features

- 📝 Apna text likho (Quran ayat, hadees, ya koi bhi nasihat)
- 🎭 4 animation styles — Fade, Slide, Typewriter, Zoom
- 📐 3 sizes — 9:16 (Reels/Shorts), 1:1 (Post), 16:9 (YouTube)
- 🎨 Custom background aur text colors
- 🌙 Bouncing emoji (chaand, dua, heart, etc.)
- 💾 Ek click me video download (WebM)
- 📱 Mobile pe bhi kaam karta hai
- 🆓 100% free, no signup, no tracking

## 🚀 GitHub Pages pe Deploy Kaise Kare

### Step 1: Repo banao
1. [github.com](https://github.com) pe login karo
2. Top-right **"+"** → **"New repository"**
3. Repository name: `ayat-video-maker`
4. **Public** select karo
5. **"Create repository"** dabao

### Step 2: Files upload karo
1. Repo ke andar **"Add file"** → **"Upload files"**
2. Ye 4 files drag karo: `index.html`, `style.css`, `script.js`, `README.md`
3. Neeche **"Commit changes"** dabao

### Step 3: GitHub Pages on karo
1. Repo → **Settings** tab
2. Left side me **"Pages"** click karo
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` aur folder: `/ (root)`
5. **Save** dabao
6. 1-2 minute wait karo
